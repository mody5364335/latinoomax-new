كل تفاصيل المنيو، في إيدك.

محرر محلي لموقع ثابت، وليس تسجيل دخول آمن على سيرفر.
الاسم وكلمة المرور بيقفلوا المحرر على جهازك فقط. المسودات على المتصفح ده فقط. التعديلات لا تظهر للزوار إلا بعد تصدير items.json ورفعه على GitHub. أي شخص يقدر ينشئ نسخة محلية، لكنه لا يقدر يغيّر الموقع المنشور بدون صلاحية GitHub. ما تستخدمش كلمة مرور حساب تاني.

إعداد المحرر على الجهاز ده

اختار اسم وكلمة مرور للمحرر المحلي. مفيش حساب عام أو باسورد افتراضي.

معاينة المسودة ↗
إزاي أنشر التعديلات؟
  1. عدّل الأصناف واحفظ. دي مسودة محلية فقط.
  2. صدّر ملف items.json واحتفظ بنسخة Excel احتياطية.
  3. افتح مستودع الموقع في حساب GitHub المالك. استخدم Add file ثم Upload files وارفع items.json في جذر المشروع، ووافق على Commit changes.
  4. استنى نشر GitHub Pages، وبعدها افتح المنيو بدون preview وراجع التعديلات.

استيراد ملف بيستبدل قائمة الأصناف بالكامل بعد التأكيد. أسماء الأعمدة الأساسية: Category, Item, Description, Size/Variant, Price, Currency. ملف التصدير بيشمل كمان ID, Image, Priority, Available, Offer, Addon IDs. رقم الأولوية الأصغر يظهر الأول داخل القسم. الصور ممكن رابط https أو رفع صورة صغيرة، بحد أقصى 500KB للصورة.

لو نسيت كلمة المرور المحلية، امسح بيانات الموقع من إعدادات المتصفح. ده بيمسح المسودة كمان، فصدّر نسخة احتياطية بانتظام.

استقبال الطلبات

ما تدخلش رقم إلا لو هو المعتمد لاستقبال طلبات العملاء. الرقم بيتنشر في ملف المنيو.
